Competências de Curadoria

Defina quais aspectos do atendimento o sistema deve analisar. Para cada competência, você escolhe um nome e escreve um prompt descrevendo o que a IA deve observar nos chamados — o sistema vai avaliar cada atendente automaticamente com base nesses critérios.

Se você acrescentou uma competência nova ou alterou o prompt de uma existente, os chamados já analisados continuam com o resultado antigo. Use o botão abaixo para apagar as competências já calculadas — elas serão recalculadas aos poucos, conforme cada atendente for aberto na tela de Curadoria.

Peso do Score de Performance

O score de cada atendente (0-1000) combina 4 dimensões. Ajuste o peso de cada uma — a soma precisa fechar em 100%. A mudança vale para os próximos cálculos (não recalcula automaticamente o histórico já exibido).

Prompt de Análise Principal (IA)

Prompt usado para analisar cada chamado (comportamento do atendente/cliente, causa, urgência, etc.) durante o "Processamento de Chamados Pendentes". Você pode reescrever livremente as regras e usar os placeholders: {{solicitante}}, {{fato}}, {{causa}}, {{moduloXRotina}}, {{owner}}, {{abertoEm}}, {{slaInicioEm}}, {{resolvidoEm}}, {{tempoResolucaoMinUteis}}, {{tempoResolucaoHorasUteis}}, {{tempoResolucaoDiasUteis}}, {{tempoResolucaoLegivel}}, {{aberturaForaExpediente}}. O formato JSON de saída é definido pelo sistema (necessário para gravar os dados no banco) e é sempre acrescentado automaticamente ao final — não precisa (e não deve) incluí-lo aqui.


                        

                    


                    

                        
Prompt de Classificação de Competências

                        
Instrução (system prompt) usada para classificar, em lote, quais competências (definidas na aba Curadoria) se manifestam em cada chamado. A lista de competências e chaves já é injetada automaticamente — este prompt define só o comportamento do avaliador.

Placeholders disponíveis no template de usuário: {{totalAtendentes}}, {{totalChamados}}, {{feedbackRateEquipe}}, {{slaEquipe}}, {{topProdutividade}}, {{topSla}}, {{menosFeedback}}, {{precisamApoio}}.

                        

                            
                            
                        

                        

                            
                            
                        

                        

                            
                            
                        

                        

                    


                    

                        
Consulta ao Banco — Listagem da Curadoria

                        
Define quais chamados aparecem na tela de Curadoria. No modo guiado, escolha o limite e a ordenação. Se precisar de uma condição diferente, ative o modo avançado e escreva a condição WHERE (sem ;, comentários ou comandos de alteração — apenas a condição booleana).

                        

                            
                            
                        

                        
                        
                        

                            
Atenção: esta condição substitui totalmente o filtro padrão da listagem. Escreva apenas a condição (ex: processado = 1 AND owner_team = 'Equipe X'), sem ; nem comandos de alteração de dados.

                            
                        

                        

                            
                            
                        

                        

                    


                    

                        
Consulta ao Banco — Fila de Processamento (IA)

                        
Define quais chamados entram na fila do "Processamento de Chamados Pendentes". No modo guiado, escolha o valor de processado considerado pendente e a ordem de processamento.

                        

                            
                            
                        

                        
                        

                            
Atenção: esta condição substitui totalmente o filtro padrão da fila. Escreva apenas a condição (ex: processado = 0), sem ; nem comandos de alteração de dados.

Prazo de resolução (em horas úteis) considerado dentro do SLA para cada urgência. Usado no KPI "Cumprimento de SLA" da Visão Geral, no comparativo da equipe e no detalhe por atendente. Critério de Estouro de SLA por Culpa do Cliente (IA)

                        
Quando um chamado estoura o prazo de SLA de resolução, a IA analisa as ações do chamado (autores e datas) para decidir se o atraso foi causado pelo suporte ou pelo cliente (ex: suporte sinalizou a solução e o cliente demorou a confirmar/responder). Esse texto é acrescentado ao "Prompt de Análise Principal" — não precisa repetir o formato JSON. Placeholders disponíveis: {{slaResolucaoHoras}} (prazo da urgência do chamado) e {{tempoResolucaoHorasUteis}} (tempo real já calculado).

Classificação de Ticket

                            
Opcional. Filtra a carga full pelo campo "Classificação de Ticket" (ex: Ouvidoria, Suporte Técnico, Gestão de Combate ao Churn). Em branco = todas as classificações.

                            
                        


                        

                            
Equipe (ownerTeam)

                            
Opcional. Filtra direto pelo campo "Equipe" do Movidesk — bem mais rápido pra API do que a Classificação de Ticket. Pode usar sozinho ou junto com a Classificação acima (nesse caso a Classificação só confirma/corrige o valor depois de buscar, o filtro na API é feito pela Equipe). Em branco = usa o mapeamento automático quando a Classificação tiver equipe conhecida (ex: Ouvidoria).
